# TornFCA v0.10.1 — Pre-1.0 Hardening

v0.10.1 is the pre-1.0 release-hardening line. It does not change the stable/main release by itself.

## Canonical command shell
- The approved five-section command center — Home / Members / Training / Operations / More — is now the canonical shell for both Beta and the eventual production candidate.
- Beta keeps its side-by-side package and visible Beta identity.
- Production uses the same command layout/live gauges with normal `TORN FCA` branding and the normal TornFCA mark.
- Legal acceptance, War compatibility routes and legacy internal home returns are redirected back to the command shell rather than the old current shell.
- Command pages remain isolated from the legacy global brand/Premium observer that previously caused stray or blank command UI mutations.
- The inherited pre-auth/login view receives lightweight TornFCA branding without installing the legacy observer.

## Premium boundary
- Free remains the complete faction core.
- Premium is convenience/depth rather than faction authority.
- Free leadership keeps 7-day Activity; Premium gets 30-day Activity history.
- Premium adds Personal Insights, advanced war alert timing, Faction Pulse and Member Dossier.
- Basic WarPay, Banking, Armory, Company Train Calculator, faction chat, core warfare, moderation/safety and basic FFScouter/TornStats access remain Free where the user otherwise has the required Torn/provider permission.
- Premium entitlement checks are centralized through `PremiumAccess`.
- Developer Premium simulation defaults OFF and is owner-only.

## Backend hardening
- Faction backend 1.1.0: current tenant/role scope per request.
- Community backend 1.5.0: fresh faction scope plus locked duplicate-sensitive writes.
- Premium backend 1.2.0: receipt idempotency, stacking fix, safe password bootstrap and fail-closed monetization switch.
- Developer backend 1.3.0: remote control plane + aggregate unique/current user telemetry.
- WarPay backend 1.1.0: fresh leadership scope + locked cloud upserts.

## Monetization safety
- Automatic payment processing defaults OFF through `MONETIZATION_APPROVED=false`.
- Backend-verified Premium can still be fully tested with owner manual grants.
- Production payment activation is a separate Torn/distribution-policy release gate.

## Legal/privacy
- Legal acknowledgement moved to `2026-08-17-v4`.
- API-key entry now shows the required data/key-use disclosure before connection.
- Cloud faction workflow data, telemetry, FCM and optional providers are documented in-app.

## Release gates
- Added/updated Premium Matrix, pre-1.0 source, canonical command-shell/mobile navigation, Community security, member-core, backend-live and cloud-candidate audits.
- Added `docs/V0.10.1_RELEASE_GATE.md` and `docs/MONETIZATION_RELEASE_GATE.md`.
- v1.0.0 remains reserved for live deployed backends + verified audits + permanently signed device-tested candidate.
